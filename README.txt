# BrainByte — Playable Version

Folder structure:

BrainByte/
├── index.html
├── style.css
├── script.js
└── Data/
    └── question.js

Open `index.html` in a browser.

Gameplay:
1. Start Game or New Game.
2. Click one or more suspicious lines in DEBUGGING CODE.
3. Click CHECK ANSWER.
4. Correct answer unlocks NEXT LEVEL.
5. Wrong answer costs one life but allows you to retry.
6. Timer reaching zero costs a life and reloads the level.
7. Progress and score are saved in localStorage.

The dark-green visual direction and main-design layout are preserved.
